## 🚀 How to Run

1. Make sure you have **JDK 8+** installed
2. Clone the repo:
```bash
   git clone https://github.com/YOUR_USERNAME/java-swing-gui-lab.git
```
3. Open in **Eclipse IDE**
4. Run any `.java` file with a `main()` method
